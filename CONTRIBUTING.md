# Contribuer

Ouvrir une issue avec versions HA/MA, navigateur, protocole et modèle d’enceinte, résultat attendu et observé. Retirer toutes les données personnelles. Proposer une petite modification accompagnée de tests pertinents. Ne pas déclencher de lecture réelle dans les tests automatisés. Conserver la validation des destinations, les restrictions administrateur et les limites mémoire/durée.

Priorités : première installation en environnement vierge, options/rechargement/désinstallation, navigateur iOS, compatibilité multiroom, mesure de latence, restauration Spotify. L’interface actuelle est en français ; les traductions sont bienvenues.
